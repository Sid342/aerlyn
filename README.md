# Aerlyn Studio

Interactive web app for Aerlyn smart home automation. Rebuilt from the legacy single-file site.

Three features under one roof:
- **A. Interactive House Explorer** — pick a home type, shape rooms, build the device list, export an order.
- **B. Touch Plate Designer** — port of the feturtles 8-step plate configurator.
- **C. Scene Builder** — compose and export automation scenes.

**Stack:** React + Vite, static hosting, no backend.

See `docs/superpowers/specs/` for the PRD and feature specs.
Reference material (legacy site, feturtles source, handoff doc) in `assets/reference/`.
